# Contributing to FindItCampus

Thanks for helping make campus life easier! 💜

## How to contribute

1. **Fork** the repository and clone your fork.
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes and test them on an emulator or device.
4. Commit with a clear message: `git commit -m "Add: short description"`
5. Push and open a **Pull Request** describing what you changed and why.

## Guidelines

- Follow the existing Kotlin code style and Android best practices.
- Keep pull requests focused: one feature or fix per PR.
- Add screenshots to the PR for any UI change.
- Be kind and respectful in discussions.

## Reporting bugs / requesting features

Open an [issue](https://github.com/aryanchand227/FindItCampus/issues) with steps to reproduce (for bugs) or a short description of the idea (for features).
