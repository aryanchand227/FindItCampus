## 📖 About

Every campus has the same problem: ID cards, earbuds, water bottles, and notebooks go missing every day, and the only "system" is a noticeboard or a crowded group chat.

**FindItCampus** replaces that chaos with one simple place to report lost items, post found items, and match them up, so belongings get back to their owners quickly.

## ✨ Features

| | Feature | Description |
|---|---|---|
| 📝 | **Report Lost Items** | Describe what you lost, where, and when, with photos. |
| 📦 | **Post Found Items** | Found something? List it in seconds so the owner can claim it. |
| 🔍 | **Smart Search & Filters** | Browse by category, location, or date to find a match quickly. |
| 📍 | **Campus Locations** | Tag items to library, canteen, hostels, classrooms, and more. |
| 🔔 | **Instant Updates** | Get notified when a matching item is reported. |

## 🚀 Getting Started

### Prerequisites

- [Android Studio](https://developer.android.com/studio) (latest stable version)
- JDK 17 or newer
- An Android device or emulator running a recent version of Android

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/aryanchand227/FindItCampus.git

# 2. Move into the project
cd FindItCampus

# 3. Open it in Android Studio and let Gradle sync
```

### Run the app

1. Open the project in **Android Studio**.
2. Wait for the Gradle sync to finish.
3. Select a device or emulator.
4. Click **Run ▶️**.

Or build from the command line:

```bash
# macOS / Linux
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

The debug APK will be at `app/build/outputs/apk/debug/`.
